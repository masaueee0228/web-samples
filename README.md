# さいたま市内事業者向け営業サンプル

上原が個人の副業として制作した、スマートフォン向けWebサイトの非公式営業サンプルです。

- 実在事業者の公式サイトではありません。
- 社名、ロゴ、電話番号、メールアドレス、詳細住所はマスキングしています。
- 各ページに `noindex,nofollow,noarchive` を設定しています。
- `robots.txt` でも全クローラーを拒否しています。

## サンプル

- `auto-care-a/`: 自動車整備店
- `leather-care/`: 革製品修理工房
- `piano-care/`: ピアノ調律・販売工房
- `tatami-care/`: 畳店
- `auto-care-b/`: 自動車整備・鈑金塗装店
